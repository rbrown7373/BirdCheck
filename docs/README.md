# BirdCheck — User Guide and Knowledge Base

**A life list should be a checklist.**

BirdCheck helps birders maintain a personal Life List, use reusable bird checklists, record Outings and quick Sightings, review observations on a map, and ask BirdCheck AI questions about their own records or the bird catalog. Apple Watch can assist with recording an Outing and adding birds by voice.

> **Documentation status:** Draft for BirdCheck **1.0, build 8** (source snapshot of October 29, 2026). This handbook is grounded in the project source and selected real-device tests. It is **not** an announcement that Apple has approved this build. Verify the wording and screenshots against the final shipped app before publishing.
>
> **Privacy:** The examples in these documents are fictional. Do not publish a developer's actual Life List, coordinates, account information, personal backups, or customer records to a public repository.
